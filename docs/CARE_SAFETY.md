# 목양 돌봄·안전 경계

Exegete는 성경 연구·묵상 보조 도구이지 상담 기록 시스템이나 위기 대응 서비스가 아니다. 일반 주해·묵상에는 이 문서의 안전 문구를 자동으로 삽입하지 않는다.

## 요청 라우팅 전 점검

`src/router.py`의 로컬 프리플라이트는 요청을 저장하거나 원문을 출력하지 않고 실행 계획만 만든다. 자해·자살, 즉시 폭력·학대, 급성 자타해 위험 신호는 `safety_first`를 우선한다. 이는 보수적인 분류일 뿐 진단이 아니며, 지역의 즉시 도움, 신뢰할 사람, 적절한 전문가 연결을 먼저 권한다. 진단, 비밀보장 약속, 법률·의료 판단, 하드코딩된 연락처는 제공하지 않는다.

비긴급 사별·투병 요청은 돌봄 인지 계획으로 표시한다. 원인을 단정하지 않고, 신앙만으로 치료하라고 하거나 회복을 보장하지 않는다.

이메일·전화번호·주민등록번호처럼 실제 식별 패턴이 보이면 `privacy_review`로 멈춘다. 개인 식별정보, 상세 사연, 저작권 본문 전문은 요청 저장, 감사 증거, 파일명, 공유물에서 제외하거나 익명화한다.

## 초안과 민감한 자료

기존 민감 자료나 초안을 바꿀 때는 명시된 대상만 읽고, 필요한 범위만 병합한다. 저장 전에는 diff, 저장 경로, 공유·내보내기 범위를 다시 확인한 뒤 쓴다. 삭제는 좁고 명시적인 요청에만 따른다.

Exegete에는 외부 전송, 계정, 보관 기한 관리 기능이 없다. 이 도구가 개인 사연을 전송·보관·사례 관리한다고 가정해서는 안 된다.
