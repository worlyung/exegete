# 한국어 자연어 요청 라우팅 골든셋

이 문서는 Exegete를 한국어로 호출하는 상위 에이전트의 **의도 판별·데이터 게이트·안전 응답**을 검증한다. 문장 표면이 정확히 일치하는지를 시험하는 목록이 아니다. 각 사례와 의미가 같은 존댓말, 줄임말, 어순 변경, 복수 요청도 같은 라우팅 결정을 내려야 한다.

## 검증 범위와 판정 원칙

한 사례는 아래 다섯 항목이 모두 맞을 때 통과한다.

1. 요청의 주된 산출물을 기준으로 모드를 고른다. 키워드가 여럿이어도 무조건 모든 도구를 실행하지 않는다.
2. 필요한 본문·원어·사전·관주 데이터를 먼저 확인한다. 없는 데이터를 기억이나 그럴듯한 설명으로 대체하지 않는다.
3. 표에 적힌 필수 명령 또는 동등한 데이터 추출을 수행한다. 본문 인용은 반드시 `lookup.py`의 실제 출력에서만 가져온다.
4. 결과가 갖춰야 할 구성과 경계를 지킨다. 원어·사전·역사적 사실·저작권 본문을 꾸며내지 않는다.
5. 정보가 부족하거나 사용자의 선택이 결과를 크게 바꾸는 경우에만 짧은 보완 질문을 한다. 질문이 불필요한 경우에는 문서의 기본값을 밝히고 진행한다.

### 판정 우선순위

| 우선순위 | 먼저 판정할 것 | 통과 조건 |
|---|---|---|
| 1 | 저작권·재배포 요청 | 합법적으로 사용자가 제공한 로컬 자료만 다루고, 저작권 본문을 내려받거나 저장소에 넣거나 대량 전재하지 않는다. |
| 2 | 설치되지 않은 필수 데이터 | 설치 명령과 영향(원어 약 100MB, 네트워크 다운로드 등)을 알리고, 사용자가 원하면 설치한 뒤 재개한다. 설치 전에는 빈칸을 사실처럼 채우지 않는다. |
| 3 | 요청 범위·대상 모호성 | 구절, 번역어/원어, 교단, 기간·회차처럼 결론을 바꾸는 한 가지를 질문한다. |
| 4 | 주된 작업 모드 | 주해, 묵상, 단어·주제, 절기, 시리즈, 배경, 병행본문, 성경공부, 통독 중 사용자가 원하는 산출물을 우선한다. |
| 5 | 보조 작업 | 비교·관주·원어·워드 내보내기는 주된 작업에 실제로 필요하거나 사용자가 명시했을 때만 덧붙인다. |

### 로컬 계획 라우터 계약

`src/router.py`는 위 원칙을 실행하기 위한 로컬 JSON 계획 라우터다. `direct_output: false`, `store_request: false`가 항상 포함되며 요청 원문을 출력하거나 저장하지 않고, 기존 CLI를 실행하지도 않는다. 계획의 `actions`는 후속 실행자가 사용할 명령 템플릿일 뿐 결과가 아니다. 자해·자살·즉시 폭력·학대·급성 자타해 위험은 `safety_first`, 실제 이메일·전화번호·주민번호 패턴은 `privacy_review`를 먼저 반환한다. 비긴급 사별·투병은 `care_aware`로 표시한다. 이 분류는 보수적 프리플라이트이며 진단이 아니다.

## 데이터 상태 표기

| 상태 | 확인 대상 | 이 저장소의 현재 기본 상태 | 라우터의 행동 |
|---|---|---|---|
| `B0` | `src/data/bible_korean.txt`, `src/data/web.txt` | 있음 | 한국어 개역한글 또는 WEB 본문 조회·번역 본문 검색은 바로 가능하다. 본문 우선순위는 사용자 제공 `bible_krv.txt` → `bible_korean.txt` → `web.txt`이다. |
| `O0` | `src/data/original/greek/`, `src/data/original/hebrew/` | 없음 | 원어·스트롱·원어 단어 검색은 실행하지 않고 `python setup_data.py`를 안내한다. 설치 후에만 `greek_lookup.py`, `hebrew_lookup.py`, `word_search.py`를 사용한다. |
| `O1` | `src/data/original/greek/`, `src/data/original/hebrew/` | 사용자가 설치한 뒤 | 본문 정경에 맞는 원어 조회를 실행하고, 실제 출력에 있는 형태소 정보만 쓴다. |
| `L0` | `src/data/lexicon/*_lexicon.json` | 없음 | `--lex` 요청은 `python src/build_lexicon.py`가 필요하다. 미설치 시 사전 정의를 기억으로 보완하지 않는다. |
| `L1` | `src/data/lexicon/*_lexicon.json` | 사용자가 설치한 뒤 | `--lex` 출력의 사전 정의와 확장 스트롱 번호를 대조해 쓴다. |
| `X0` | `src/data/xref/cross_references.json` | 없음 | 관주가 필요한 요청은 `python src/build_xref.py`를 안내한다. 설치 전에는 관련 구절 목록을 지어내지 않는다. |
| `X1` | `src/data/xref/cross_references.json` | 사용자가 설치한 뒤 | `xref.py`가 실제로 반환한 구절·순위만 관주 결과로 제시한다. |
| `S0` | `src/data/bible_krv.txt` 또는 소제목 포함 사용자 본문 | 없음 | `series.py`는 기본으로 `bible_krv.txt`를 찾고 소제목을 단락 경계로 쓴다. 소제목이 있는 합법적 사용자 본문 또는 `EXEGETE_BIBLE` 지정이 필요하다. 현재 내장 `bible_korean.txt`에는 소제목이 없다. |
| `S1` | 소제목 포함 사용자 본문 | 사용자가 준비한 뒤 | 실제 소제목 경계로만 시리즈 회차를 제안하고, 요청 회차 수와 자연 단락 수가 다르면 병합·분할 동의를 받는다. |
| `C1` | 사용자 제공 개역개정·NA28·BHS 등 | 저장소에 없음 | 사용자의 합법적 접근 자료를 개인 로컬 용도로만 형식에 맞춰 쓴다. 저장소 추가, 공개 배포, 대량 전재는 하지 않는다. |

`setup_data.py`, `build_lexicon.py`, `build_xref.py`는 네트워크에서 데이터를 내려받아 로컬 파일을 만든다. 사용자가 단지 결과를 요청했을 뿐 설치를 명시적으로 요청하지 않았다면, 자동 설치 대신 필요한 설치를 한 문장으로 설명하고 진행 의사를 확인한다.

## 사람·자동화 공용 실행 절차

1. **의도 추출**: 요청에서 대상(구절·장·책·절기·주제), 원하는 산출물, 전통·번역·분량·문서 형식을 분리한다.
2. **위험/데이터 게이트**: `C01`~`C04`를 먼저 적용하고, 이어 `B0`/`O0`/`L0`/`X0`/`S0` 상태를 검사한다.
3. **주 모드 선택**: `R01`~`R14` 중 가장 가까운 하나를 고른다. 예를 들어 “부활절 본문으로 QT”는 먼저 절기 후보를 얻고, 사용자가 고른 구절에 `R03`을 적용한다.
4. **실제 데이터 추출**: 표의 `lookup.py`, 원어 조회, 검색, 절기·배경·시리즈 명령을 실행한다. 오류 메시지가 나오면 같은 범주의 `E01`~`E09` 처리를 적용한다.
5. **산출물 검사**: 아래 체크리스트로 내용·안전성을 점검한다. 기대한 자연어 문장 자체가 아니라 이 조건의 충족 여부를 판정한다.

### 공통 합격 체크리스트

- [ ] 구절을 포함한 결과라면 `lookup.py` 출력의 실제 본문만 인용했다.
- [ ] 원어·스트롱·문법·사전 정의는 설치된 데이터에서만 가져왔고, 불확실한 항목은 `[확인 필요]`로 남겼다.
- [ ] 주해라면 4단계와 단계별 품질 점검, 마지막 AI 한계 고지를 포함했다. 묵상·통독에는 요청된 가벼운 형식을 지켰다.
- [ ] 4단계 주해를 완성본으로 공유하거나 Word로 내보낼 때는 감사 결과가 `PASS`, 또는 모든 사실이 `PASS`이고 동의가 기록된 `WARN`이며 감사 뒤 초안 해시가 바뀌지 않았다.
- [ ] 신학 전통은 사용자 지정이 있으면 따랐고, 없으면 공통 견해와 쟁점을 구분했다.
- [ ] 배경 연구는 본문·역사/지리·신학의 3층을 섞지 않았으며, `high` 논쟁은 양쪽 견해를 병기했다.
- [ ] 절기·병행본문·관주는 데이터로 확인한 범위만 말했고, 확인 불가 범위는 질문 또는 설치 안내로 처리했다.
- [ ] 저작권 번역·원문을 내려받기, 커밋, 대량 전재, 재배포하지 않았다.
- [ ] 보완 질문은 결과를 바꾸는 최소 한 가지이며, 이미 주어진 정보를 다시 묻지 않았다.

아래 중 하나라도 발생하면 해당 사례는 실패다.

- `O0`, `L0`, `X0`, `S0`에서 설치·입력 안내 없이 그 데이터를 사용한 것처럼 답한다.
- 번역 본문 검색의 빈도를 원어 단어의 빈도 또는 신학 주제의 총횟수라고 부른다.
- 절기 매칭, 병행본문, 역사적 연대·경로를 확인하지 않고 지식으로 단정한다.
- 요청이 “짧은 묵상”인데 4단계 논문형 주해를 강제하거나, 반대로 명시적 4단계 주해를 QT 형식으로 축소한다.
- 사용자가 제공하지 않은 저작권 번역·비평 원문을 찾아서 저장하거나 대량 인용한다.
- 히브리어·아람어 원문을 고정폭 구조 도표에 넣어 RTL 정렬이 깨지게 한다. 구조 도표에는 음역·번역을 쓰고 정밀 원어 정보는 표에 둔다.
